## 🚀 About Me

- Mobile and IoT Software Engineer with a background in Electronics & Telecommunications.
- Experienced in building native Android apps using Kotlin and integrating them with physical devices via BLE, Bluetooth Sockets, Wi-Fi, and cloud APIs.
- Currently expanding into full-stack enterprise development as a Systems Engineer at Tata Consultancy Services (TCS), working with React.js and Spring Boot.
- Formerly the Founding Android & IoT Engineer at a startup, where I architected hardware-connected Android applications from scratch.
- Independently developed and shipped the "Arduino Bluetooth Controller" app, achieving over 13,000 organic downloads on Google Play.
- Passionate about Clean Architecture, MVVM, asynchronous communication (Coroutines/Flow), and cross-platform exploration with Flutter.

## 🏆 Featured Highlights

- **13K+ App Downloads:** Shipped an Android application for real-time control of Arduino/ESP-based hardware using Bluetooth Sockets, scaling to over 13,000 organic users.
